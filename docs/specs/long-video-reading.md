# 长视频阅读与全文架构图

状态：已按用户修正实现；验证和交付见文末。更新：2026-09-27。

## 目标与场景

用户阅读长视频摘要仍觉得长文本疲劳，希望快速理解全文的内容组织方式，并按需查看细节。

用户明确修正：“这个不是我要的，我希望图是一个单独的文章内容架构的图。”随后选择“全文大纲图：中心主题 → 各章节 → 子主题，覆盖整篇内容”。本规格以这次修正为准。

## 已确认范围

- 全文架构图是一张独立的大纲图，覆盖全部已生成章节及其要点。生成结果最多 8 章，相关话题合并后仍需覆盖全文。
- 侧栏在简短结论下直接展示完整架构图片，与文字摘要分开。点击图片在侧栏内放大、缩放和滚动；独立页面及 SVG 导出作为可选入口。
- 中心主题采用视频标题，第一层为语义章节，第二层为该章要点。连线表示内容归属，不推断因果或论证。
- 全文架构图不受三个节点、约 100 字的摘要预算约束。无需额外调用模型；已有完整摘要可以直接打开图。
- 用户可缩放、查看全图、恢复原始大小、滚动查看和导出独立 SVG。保留可访问的文字大纲。
- 章节全文继续按需展开，Markdown 保留完整内容；只有显式时间按钮才跳转视频。
- 不新增音频、问答、章节编辑、因果推导或外部图形服务；版本保持用户指定的 0.1.21。

## 可观察的验收

1. 处理结果最多 8 章，图中保留全部章节分支及已有子主题；模型超限时重试合并，不截掉末尾章节。
2. 侧栏直接展示一张相连的中心主题、章节、子主题大图。点击图片打开本地放大视图，不打开新标签页；可选按钮仍可打开独立页面导出。
3. 长标签自动换行，不能截断结论或遗漏关键条件。没有要点的章节仍保留章节，不编造子主题。
4. 查看全图可以观察整体层次；放大和原始大小支持细读，超出画布的部分可滚动查看。
5. SVG 导出包含全图和文本，不依赖扩展脚本、网页截图或远程资源；文字大纲表达相同层次。
6. 旧提示版本 6/7/8 中不超过 8 章的摘要无需重新生成即可查看图；超过上限的缓存不再载入，需要重新处理。打开后切换原视频，不改变已打开的图。
7. 内嵌图片不依赖图会话存储。独立页图会话丢失时明确提示从侧栏重新打开。创建页面失败时保留当前摘要并显示错误，不重复调用模型。
8. 测试十六章、无子主题、长文本、特殊字符、不同会话隔离和打开失败；浏览器验证实际独立页面、缩放与下载。真实视频内容的语义质量仍由原摘要决定。

## 实现约定

- 本地确定性布局生成一个 SVG：中心主题居中，章节按编号先左后右、由上到下阅读，子主题向外展开。全部章节与要点保留。
- 文本按可读宽度换行并进行 XML 转义，禁止把模型文字作为 SVG/HTML 标记执行。
- 独立页面读取与本次点击绑定的内容快照，只含标题、章节标题、起始时间和要点，不含字幕、密钥或模型设置。
- 快照使用 Chrome 的会话存储；扩展重载/更新或浏览器重启后会清除，已有摘要仍可重新打开图。依据 [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage#session)。
- 提示版本升至 9，缓存结构保持 6。新生成不再要求旧版 visual 字段；兼容旧版本完整章节，忽略已弃用的小图数据。
- 文字结论与完整 Markdown 保留；图形展示失败时可使用文字大纲。
